  ### 🛠️ Tools & projects I've built

  - **Power BI MCP Server** — an MCP server that lets an AI agent build a complete Power BI report and semantic model end-to-end.
  *(ONEPOINT)*
  - **DataAgent Evaluation Framework** — grades Microsoft Fabric Data Agent answers across four independent signals (answer
  correctness, query correctness, self-faithfulness, SDK critic), combined into an Accept / Need Review / Reject verdict, with
  sandbox-vs-production comparison. *(ONEPOINT)*
  - **Medallion Automation Skills** — a pair of Claude Code skills that let an AI agent run a full medallion pipeline end-to-end: one
  drives automated, idempotent Bronze→Silver ingestion; the other owns Gold-layer design (SCD type 1/4, business-key validation,
  deduplication, dimensional modeling). *(ONEPOINT)*
  - **Fabric App — Bike_App** — a Fabric App combining live semantic-model dashboards (DirectQuery + Import star schema), a Fabric
  Data Agent chat surface, and a workspace/lineage governance explorer, deployed straight into Fabric. *(ONEPOINT)*
  - **ID Document Scanning App** — Azure-based OCR pipeline that scans identity documents and auto-fills Excel, built for a client in
  the travel sector. *(Personal project)*
